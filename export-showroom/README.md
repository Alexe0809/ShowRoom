# MERIDIAN — Шоурум G700

Интерактивный шоурум частного самолёта Gulfstream G700: полёт, экстерьер с точками, проход по семи зонам салона, главы интерьера, план салона и сводные ТТХ.

## Запуск

Статическая страница, сборка не нужна. Достаточно любого локального сервера из корня папки:

```bash
python3 -m http.server 8080
# затем http://localhost:8080/
```

Открывать `index.html` напрямую через `file://` не стоит — не подхватятся `media/` и состояние слотов.

## Структура

```
index.html        # страница шоурума (Design Component)
support.js        # рантайм компонента
image-slot.js     # слоты изображений (drag & drop, сохранение кадрирования)
media/            # фотографии борта и план салона
```

## Публикация

Подходит для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Изображения

Фотографии предоставлены производителем борта и использованы в демонстрационных целях.
